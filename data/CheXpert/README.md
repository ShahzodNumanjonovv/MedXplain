# CheXpert Dataset (Project Usage)

This folder contains the preprocessed **CheXpert dataset** used in our
**MedXplain: Neuro-Symbolic Explainable Radiology VLM** project.

## 📌 Dataset Description
CheXpert is a large public chest X-ray dataset containing:
- **224,316 images**
- **14 clinically important labels**  
  (e.g., Cardiomegaly, Edema, Pneumonia, Consolidation, Pleural Effusion, etc.)

We use CheXpert as:
- Ground-truth concept labels for the **Concept Bottleneck Model (CBM)**
- Validation of concept prediction accuracy
- A smaller, lightweight alternative to MIMIC-CXR for rapid experimentation
