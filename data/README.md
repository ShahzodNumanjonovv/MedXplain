# Dataset Information

## MIMIC-CXR v2.0
- 377,110 chest X-ray images  
- 227,827 studies  
- Paired radiology reports  
- Source: PhysioNet  
- License: Credentialed Health Data License  
- Use: Training & evaluation of image–text models

## CheXpert
- 224,316 chest X-ray images  
- 14 pathology labels (e.g., cardiomegaly, edema, consolidation)  
- Source: Stanford ML Group  
- License: Academic research use  
- Use: Concept labels for Concept Bottleneck Model (CBM)

## Symbolic Rule Set
- 25–30 expert-defined rules  
- Derived from:
  - CheXpert documentation  
  - American College of Radiology (ACR) guidelines  
- Use: Logic Tensor Network (LTN) reasoning

## Notes
- No raw medical images included in this repository  
- Only dataset descriptions and paths are provided  
- Users must download datasets from official sources
